\begin{goal} \rm
Practice evaluating integrals using substitution and/or integration by parts.
\end{goal}

\begin{enumerate}
\item What do you need to remember when doing integration by parts? (e.g.\ What is the formula? When is it useful? What should you choose for $u$?)
\vspace{1.25in}


\item 
Evaluate the following integrals. Write down which integration technique you use.
\begin{enumerate}




\item Show that $\displaystyle\int_1^2 x^2 e^x \ dx = e(2e-1)$.

Hint: Do integration by parts twice.

%\vspace{1.75in}

%\item $\displaystyle\int 4x (\ln x)^2\ dx$




\vspace{2.25in}

\item  Evaluate $\displaystyle\int x^3(x^4-17)^{24} \ dx$ 

Hint: You may use substitution or integration by parts. Which one is easier?

\pagebreak

\item Show that $\displaystyle\int_e^{e^2} \frac{\ln(\ln x)}{x} \ dx = 2\ln 2 - 1$.

Hint: First use the substitution $w=\ln x$ ($u$-substitution with the variable $w$, so you don't confuse it with the $u$ in integration by parts!) then do integration by parts with $u=\ln(w)$.



\vspace{3.5in}


\item Use the substitution $u=25-x^2$ to evaluate $\displaystyle\int \frac{x^3}{\sqrt{25-x^2}} \ dx$.

Hint: If $u=25-x^2$, what does $x^2$ equal?

\pagebreak
\item $\displaystyle\int \cos^4(3x)\sin^5(3x) \ dx$
\vfill

\item Give an example of an integral that can be solved by using five consecutive applications of integration by parts.  (You do not need to solve it.)

\vfill

\item Give an example of an integral of the form $\displaystyle \int f(x) g(x) \, dx$ that can be solved using integration by parts in two ways: by letting $u = f(x)$, or $u = g(x)$.  Solve the integral both ways.

\vfill
